WAutoSequelize

WAutoSequelize

new WAutoSequelize(optopt) → {Promise}

Description:

  • 由指定資料庫生成各表的models資料

    診斷輸出(sql紀錄與錯誤)皆經單一出口：預設只輸出固定標籤與不含個資之摘要(不含sql全文、資料值、錯誤原文、路徑)，sql紀錄預設關閉；資料庫帳號與密碼於任何輸出(含opt.logDetail與opt.funLog之細節)皆以***遮罩

logDetail Boolean <optional>
 false

輸入是否還原診斷輸出之舊版細節布林值，預設false，型別錯誤者視同false。診斷輸出(console)預設只含固定標籤與不含個資之摘要(不含sql全文、錯誤原文、路徑)；為true時還原舊版輸出(sql全文以console.log，建表或外鍵查詢失敗之錯誤物件以console.error)，有洩漏個資之風險，僅供除錯使用。帳號與密碼於任何情形皆以***遮罩
funLog function <optional>
 null

輸入診斷輸出函數(label, safe, detail)，預設null，非函數者視同null。給予時診斷輸出只交給此函數(不寫console)：label為固定標籤('sql'、'foreign keys catch'、'tables catch')，safe為不含個資之摘要物件(如{ stmt: 'SELECT' }、{ errType: 'ConnectionError', errCode: 'SQLITE_CANTOPEN' })，detail為完整細節(sql全文字串、錯誤物件之副本；帳號與密碼已遮罩為***)。此函數拋錯或回傳reject之promise皆不影響產生models之流程
